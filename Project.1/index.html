01 — System
From raw downlink to decision

Four stages turn heterogeneous national datasets into a continuously corrected climate state and forward-looking scenarios — the same backbone, regardless of which variable or region is in focus.

01 · INGEST

National data sources

INSAT-3D/3DR, Oceansat, Bhuvan & MOSDAC feeds, IMD station + gridded rainfall/temperature, IMDAA/ERA5 reanalysis, hydrological records — normalised onto one spatiotemporal grid.

→
02 · FUSE

AI data assimilation

ML-based bias correction and ensemble fusion reconcile satellite retrievals with sparse ground truth, producing a continuous, uncertainty-aware "current state" of the atmosphere and land surface.

→
03 · PREDICT

Short-term forecasting

Spatiotemporal models (ConvLSTM / Temporal Fusion Transformer) trained on the fused state generate short-horizon rainfall and temperature forecasts with calibrated uncertainty bands.

→
04 · APPLY

Decision interfaces

Map dashboard, what-if scenario simulator, and sector-facing APIs (agriculture, water, disaster management) sit on top of the same fused state and forecast outputs.

05 — Path to scale
From pilot to national deployment
PHASE 1
Single-variable PoC, one region

Rainfall + temperature, Marathwada pilot, daily fusion cadence, validated against IMD station truth.

PHASE 2
Multi-variable, multi-basin

Add soil moisture, evapotranspiration and surface winds; extend to additional drought-prone basins.

PHASE 3
Sector applications

Plug-in modules for agriculture advisories, reservoir operations, and disaster early-warning.

PHASE 4
Pan-India operational twin

National-grid resolution, hourly assimilation, public + institutional API access.
